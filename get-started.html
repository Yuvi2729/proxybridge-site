Install in a few steps

Everything you need to get Proxy Bridge running on your Mac.

01

Download Proxy Bridge

Click the download button above. Your browser will download the Proxy Bridge DMG installer.

ProxyBridge.V26.0.dmg
02

Open the DMG

When the download finishes, open the downloaded .dmg file from your Downloads folder.

03

Move to Applications

Finder will open with the installer. Drag Proxy Bridge into your Applications folder.

Proxy Bridge → Applications
04

Open Applications

Open Finder → Applications and locate Proxy Bridge.

05

Allow macOS to open the app

If macOS shows a security warning, close it, right-click Proxy Bridge, and choose Open. If needed, go to System Settings → Privacy & Security and select Open Anyway.

06

Launch Proxy Bridge

Confirm the prompt by clicking Open. Proxy Bridge will launch and you're ready to start editing.

First launch security notice

Proxy Bridge is currently distributed outside the Mac App Store and may show a macOS security warning on first launch. This is expected for an app that has not been notarized by Apple.
