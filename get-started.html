macOS Installation Guide

Install ProxyBridge

Download ProxyBridge, move it to Applications, and launch it on your Mac in a few simple steps.

   Download ProxyBridge for macOS
1

Download ProxyBridge

Click the button above. Your browser will download the ProxyBridge DMG installer.

ProxyBridge.V26.0.dmg
2

Open the DMG

After the download finishes, open the downloaded .dmg file from your Downloads folder.

3

Install ProxyBridge

A Finder window will appear. Drag the Proxy Bridge app into the Applications folder.

Proxy Bridge → Applications
4

Open Applications

Open Finder → Applications and find Proxy Bridge.

5

Allow macOS to open the app

If macOS shows a security warning, close the warning, then right-click Proxy Bridge and choose Open. If macOS still blocks it, go to System Settings → Privacy & Security and choose Open Anyway when that option is available.

6

Launch ProxyBridge

Confirm the prompt by clicking Open. ProxyBridge will now launch and you can start using the app.

First launch security notice

ProxyBridge is currently distributed outside the Mac App Store and may show a macOS security warning on first launch. This is expected for an app that has not been notarized by Apple.
